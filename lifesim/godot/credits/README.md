# V0.11 external asset provenance

Assets in `art/third_party/kenney/` are Kenney's original City Kit Suburban, City Kit Commercial, City Kit Roads, Furniture Kit, and Food Kit models, redistributed as glTF binaries through `Hidencod/tge-assets`. Each asset is licensed **CC0-1.0**; see the copyright holder's own pages at https://kenney.nl/assets/ and the repository https://github.com/Hidencod/tge-assets.

The exact GitHub source revision is `3ddcc695adbba9fb918cf31b7c139b3f95b76910`. `KENNEY_ASSETS_V11.json` lists each file, its original GitHub repository path and Git blob SHA-1, checked during CI. These models are NOT from a commercial game and the city layout is fictional; it is not a meter-for-meter reproduction of a real neighborhood.

The original V0.10 character assets, architecture assets and textures remain independently authored. No paid materials or runtime CDN use.
