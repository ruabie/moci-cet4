# 同频之城 / V0.6 生活循环更新（候选）

当前是 Godot 4.7.2 单人 3D 人生模拟的独立开发版本。实际运行和网页部署需以 CI 及真实浏览器测试为准，不能把静态代码检查当作通过。

## V0.6 生活内容

- 两套可操作工作：AOI MART 收银、KAWA COFFEE 制作饮品。每次三道有选项的订单题，按 1、2、3 回答，正确数量影响报酬；每次耗费精力，完成当天第一份兼职有额外奖励。
- 每日配送：便利店按 K 领取包裹，步行抵达公园对面的河畔取件箱，按 E 完成交付，只能结算一次。
- 街景摄影：靠近公园河岸、路口、生活商店橱窗按 P 拍照，保存真实 PNG 到 user://photos/，屏幕短暂显示相片预览；每天完成两个不同地点有奖励。
- 六位居民：靠近按 E 展开对话，再按 1 聊天、2 获取线索、3 告别；每日首次交流增加关系等级与心情，关系长期保存。
- 每日生活目标：打工、交友、摄影三条计划，公园实体委托板可查看，按 T 可打开最近的生活日志。
- 公寓长期成长：生活商店按 B/E 打开家具菜单，数字 1–5 购买阅读灯、地毯、绿植、书架、电脑，返回公寓后家具实际出现；永久保存，家具改善在家休息的心情收益。
- 真实室内：AOI MART、KAWA COFFEE 可步行到门口并按 E 进入独立商店室内，Q/E 返回街区；回公寓按 R 恢复精力。
- 钱包、精力、心情、工作经验、人物关系、配送、每日日志持久化；时间继续严格使用本机真实时间。

## 操作

WASD 移动 / 鼠标视角 / Shift 跑步 / E 交互 / J 工作 / 1、2、3 答订单和对话 / B 购买 / K 接配送 / P 摄影 / R 休息 / T 日志 / Q 离开室内。

## 验证要求

1. 用 Godot 4.7.2 导入资源并运行 `--headless --path . --script res://tests/qa_headless.gd`；需要本机渲染截图。
2. `CitySave.sanitize` 必须兼容旧版 V0.5.1 存档，奖励不可重复，领取/投递不能出现重复计费。
3. Web 版使用单线程兼容渲染，并随构建包含 OFL 中文字体。
4. 仍然没有完整开放世界、复杂经济与智能 NPC；画面和操作体验还未达到商业品质。

> 注：用户数据存于浏览器/设备的本地用户存储，清理站点数据可能导致存档和摄影作品丢失。无服务端的游戏不能保证防止修改本机时间作弊。
