# 同频之城 V0.17 · 便利店冷柜与表面材质整改

## 已完成的源代码范围
- 便利店三组冷柜改用有实际中空空间的柜体。背板、底座、独立货架、半透明门、金属拉手和柜内冷白灯带均有自己的模型几何，不再把半透明玻璃直接贴在实心黑箱表面。
- 72 件冷藏商品位于玻璃后方的真实层板上，保留 V0.16 货架中的 8 类原创 SKU 和 MultiMesh 批量渲染机制。
- 新增可复现、无外部图库依赖的瓷砖、灰泥和木饰面材质（每种 512×512 颜色图和法线图）。
- 保留两栋商铺的连续进出、现实时间、经济、工作、NPC 与存档系统；这不是扩地图版本。

## 质量门槛及其限制
- 必须通过 Godot 4.7.2 源码解析、角色真实步行进出便利店与相机碰撞测试。
- 必须通过 V0.17 资源校验、三组中空冷柜、72 件冷藏商品与六条内灯带的运行时验证。
- 需取得 V0.16 固定机位、新冷柜近景和店面画面的实际 Godot 截图，确认透明层级、室内曝光和尺寸比例。
- Web 端需在独立 lifesim/play-v17 路径导出和实测，不能覆盖过去网页或修改其他游戏。
- **未解决**：人物建模、全街区材质一致性、公寓连续进出与 Windows RTX 3060 真机 FPS。不得宣称整体美术已经合格。
