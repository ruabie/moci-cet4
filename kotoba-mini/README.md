# ことば · 微信原生小程序 V0.1（审核前开发版）

独立路径：`kotoba-mini/`。不覆盖网页 `kotoba/` 或其他游戏项目。

## 状态
- 真实从 `main/kotoba/` 的 V7.1 源码读取并转换词库，来源快照 2026-11-22。
- 819 条原始记录、按日语词形去重 752 项；第三册 1–5，第二册 12–16。
- 原生 WXML/WXSS + JS；无服务器、无登录、无收费；独立微信本地存储。
- 保留：按课/总库/课外、10/20/自定、展示词性、双向考核、自评、延迟复习、批次不重复、考后直接继续、学习日志、跨课释义和错词记录。
- 支持导入网页版 `kotoba_pwa_v4` 所导出的 `schema:4` JSON（需先在原网页导出并发送至微信文件传输助手，再从微信聊天文件导入）。
- 暂不支持：浏览器系统语音的微信等价实现、云端同步、自动迁移浏览器 localStorage、微信实机验收。

## 开发预览
1. 在微信公众平台注册小程序，取得合法 AppID。
2. 用微信开发者工具导入本目录，开发阶段可先保留 `touristappid` 进行模拟器测试。
3. 真机体验前把 `project.config.json` 中的 AppID 改为本人小程序 AppID，并由管理员扫码授权。
4. 执行 `node --test tests/*.test.js` 验证核心逻辑；注意单元测试并不等于微信开发者工具和真机验证。
5. 发布之前完成下述全部合规闸口；不要将此分支直接合并或发布。

## 发布阻断项
- [ ] **版权**：教材照片直接录入的日语词条及印刷中文释义尚未证明具备面向公众再分发权利。对原文释义完成授权核验或改为独立编写/授权的数据后才可发布。不要因为仓库公开就推定拥有内容版权。
- [ ] **主体/类目**：在微信公众平台确认个人主体是否允许真实功能对应的类目，避免误归类“教育培训”或无证经营。
- [ ] **备案**：完成小程序备案，核查备案信息与主体一致。
- [ ] **隐私**：核对微信隐私保护指引与实际调用 API、个人信息收集情况（本版本无需登录、无网络请求）。
- [ ] **产品**：实际微信开发者工具编译、Android/iOS 真机、长词换行、学习流程、输入法、备份分享与导入、离线数据保护。
- [ ] **音频**：如要加朗读，需有符合授权且可用的 ja-JP 音频，不要直接声称已移植网页 TTS。
- [ ] **平台**：提供 AppID、管理员授权、发布资料并审核通过，才能正式上线。

## 说明
本地学习数据存储在 `wx.setStorageSync('kotoba_mini_v1')`，不会自动与网页 `localStorage` 同步。多个中文意思允许用户核对后手动判定；自动判定不是语义评分。
